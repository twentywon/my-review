# 취향록

음악 앨범·영화·드라마·게임을 직접 등록하고 별점과 한줄평을 저장하는 개인 리뷰 웹앱입니다.
Sites 계정 인증, 계정별 D1 기록 저장, R2 이미지 업로드를 사용합니다.

## 입력 흐름

1. 새 기록을 열고 제목을 입력합니다. 제목만 필수이며 나머지는 비워 두고 나중에 수정할 수 있습니다.
2. Google 이미지 검색으로 커버·포스터를 찾습니다. 내부 이미지 검색창에서 사진을 누르면 바로 적용됩니다(Serper 키 설정 필요). 파일 업로드와 Ctrl+V 붙여 넣기도 가능합니다.
3. 가수·아티스트, 감독, 제작사·개발사와 나머지 작품 정보를 직접 입력합니다.
4. 필요하면 네 자리 연도·별점·한줄평을 추가하고 저장합니다. 비어 있는 별점은 0점 대신 미등록으로 표시합니다.

## 자동완성

같은 계정에 저장된 기존 기록을 기준으로 제안합니다. 음악 아티스트·영화/드라마 감독·게임 제작사는 분야별로 구분합니다. 영화와 드라마는 감독과 배우를 공유합니다. 장르는 분야별 기본 목록에서 여러 개 선택합니다. 기존에 직접 입력한 장르는 기존 항목으로 유지합니다. 작품 종류 변경 시 새 분야 목록에 없는 장르는 선택이 해제됩니다.
여러 이름은 쉼표로 구분하며, 새 이름도 자유롭게 입력할 수 있습니다. 선택은 마우스 또는 방향키와 Enter로 할 수 있습니다.

## 로그인

앱 진입 시 로그인을 확인합니다. 검색 도중 세션이 만료되면 입력창을 유지하며 새 탭에서 다시 로그인한 후 검색을 재시도할 수 있습니다.

## 데이터 호환

저장 모델의 date 필드는 네 자리 연도를 저장합니다. 기존 YYYY-MM-DD 값은 조회 시 YYYY로 표시하고 수정 저장할 때 연도로 간소화합니다.
기존 리뷰·이미지·원문 정보는 유지합니다. 평균 별점 표시와 계산은 없습니다. 작품별 별점은 유지합니다.

## 이미지 검색

Google 페이지를 iframe으로 감싸거나 클릭을 가로채지 않습니다. 내부 검색창에서 Serper의 Google 이미지 검색 결과를 표시하고, 사진 선택 시 원본 이미지 URL을 바로 표지에 적용합니다. 이미지는 원본 사이트에서 표시하므로 외부 사이트 사정에 따라 로딩이 실패할 수 있으며 파일 업로드도 지원합니다. 작품 정보는 자동 입력하지 않습니다.

### 검색 연결

키를 설정하면 실제 검색 결과를 표시합니다. 키가 없으면 연결 안내를 표시하며 모의 결과를 표시하지 않습니다.
1. https://serper.dev/ 에서 API 키를 발급받습니다.
2. 로컬 앱의 `.dev.vars`에 `SERPER_API_KEY=발급받은키`를 추가합니다. 기존 줄은 유지합니다. 키를 채팅에 보내거나 소스에 포함하지 않습니다.
3. 개발 서버를 다시 시작합니다. 호스팅 환경에서는 서버 비밀값으로 설정합니다.

서버만 키를 사용하며 `/api/image-search`는 인증 후 검색합니다. 키 없음, 요청 실패, 결과 없음 상태를 구분합니다. 서비스 유료 결제나 가입은 자동으로 하지 않습니다. 키 연결 전에는 Google에서 직접 검색 후 이미지 복사/붙여 넣기와 업로드를 사용할 수 있습니다.
웹사이트 크롤링, 페이지 정보 추출, 외부 작품 DB 검색은 제거한 상태입니다.

## 개발 및 검증

- 로컬 DB 준비(최초 1회, 마이그레이션 추가 시 다시 실행): npm run db:local
- 개발: npm run dev
- 타입 검사: npx tsc --noEmit
- 단위 검증: node tests/manual-entry.mjs
- 통합 검증(개발 서버 필요): node tests/manual-integration.mjs
- 빌드: npm run build

개발 서버는 `drizzle/`의 마이그레이션을 자동 적용하지 않습니다. `npm run db:local`을 실행하지 않으면 로컬 DB에 `entries` 테이블이 없어 기록 저장이 500 오류로 실패합니다. 이 명령은 `.wrangler/state`의 로컬 DB에만 적용하며 이미 적용한 마이그레이션은 건너뜁니다.

JSON 내보내기로 기록을 백업할 수 있습니다. 실행 비밀값과 로컬 데이터는 소스 배포 파일에 포함하지 않습니다.

## 화면

입력 안내 메뉴와 안내 창은 제거했습니다. 연보라색 테마를 사용하며, 음악 앨범은 1:1 정사각형, 영화·드라마·게임은 2:3 세로 포스터 프레임을 사용합니다. 이미지는 object-fit: cover로 프레임을 여백 없이 채웁니다. 프레임과 원본 비율이 다르면 가장자리가 일부 잘릴 수 있습니다.

## 삭제 및 장르별 보기

카드의 휴지통 버튼 또는 수정창의 리뷰 삭제 버튼을 누르고 삭제 확인창에서 확정합니다. 취소하면 기록을 유지합니다. 장르별 보기에는 현재 분야·국내/해외 범위에 저장된 장르와 각 작품 수를 표시합니다. 복수 장르 작품은 각 장르에 포함되며, 장르 미등록과 모든 장르도 선택할 수 있습니다. 검색어·정렬과 함께 사용할 수 있습니다.

## Android 독립형 앱

음악 앨범·영화/드라마·게임 분야별 조회만 제공합니다. 모든 기록 통합 조회 메뉴는 제거했습니다.
`npm run build:mobile`로 React 화면을 Android assets에 번들링합니다. Android 프로젝트는 `android/`에 있습니다. JDK 17 이상, Android SDK 35, Gradle을 사용해 `android/gradlew.bat -p android assembleRelease`로 빌드합니다. 릴리스 서명 설정은 로컬 전용 `.sites-runtime/android-signing/keystore.properties`에서 읽으며 소스 아카이브와 APK에 비밀값을 포함하지 않습니다. 다른 환경에서는 자신의 서명 키를 생성·설정해야 합니다.

Android는 IndexedDB에 기록을 저장하고 로그인이나 PC 서버에 의존하지 않습니다. 네이티브 기능은 androidx.webkit의 출처 제한 메시지 연결을 사용합니다. Serper 키는 휴대폰 앱 설정에서 입력하고 Android Keystore로 암호화해 보관합니다. 백업 내보내기는 Android 문서 저장 창을 사용하며, 가져오기는 동일 ID를 덮어쓰지 않습니다. 업로드 이미지는 데이터와 함께 저장하고 외부 이미지 URL은 인터넷 연결이 필요합니다.

모바일 스타일은 사용하지 않는 Tailwind 유틸리티 생성을 제거했습니다. 목록 필터·정렬·집계·자동완성은 의존 데이터 변경 시에만 다시 계산합니다. 기기/서버가 공통 입력 검증을 사용합니다.

## 1.1.0

상단 소개/누적 기록 수 카드를 제거했습니다. 별 입력은 좌우 반쪽의 0.5점 라디오 버튼이며 SVG clipPath로 실제 반쪽 별을 표시합니다. 국내·해외도 라디오로 선택합니다. 페이지당 리뷰 수는 10개이며 숫자 페이지 이동·필터 변경 시 첫 페이지·삭제 후 페이지 범위 보정을 지원합니다.

검증: 반쪽 별 클릭/모바일 입력/국내·해외 상호 배타 선택, 실제 리뷰 11개에서 10개+1개 페이지 이동, TypeScript와 저장 회귀 검사, 릴리스 APK 빌드 및 기존 서명 일치 확인. 실제 Android 기기의 실행·업데이트 설치는 미확인입니다.

## 1.2.0

등록 진입점은 상단 새 기록 하나로 통일했습니다. 새 영상 작품 유형은 screen(영화·드라마)이며 기존 movie/tv는 조회·수정·가져오기 시 같은 분야로 취급합니다. 감독/배우 자동완성, 장르, 개봉/방영연도와 포스터 비율을 유지합니다.
